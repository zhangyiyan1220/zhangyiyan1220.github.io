# 《红楼梦》一分钟名著解读 · 国风动画短片

> 一段以八段框架拆解传世名著的一分钟动画短片：作者与时代、人物、剧情梗概、文学价值、主旨内核、艺术手法、版本与红学、当代阅读。画面取传统国画工笔重彩，致敬 87 版《红楼梦》；配乐由古琴、箫、琵琶、鼓与编钟合成，随八段情绪起伏。

![作品封面](封面预览.jpg)

## 关于这个仓库

这是《红楼梦》一分钟短片的作品展示网页。图片素材内嵌在 `index.html` 中，视频与配乐为同目录下的独立文件（`film.mp4`、`music.m4a`），通过相对路径加载——这是为了让浏览器能正常解码视频（超大的内嵌视频 data URI 会导致黑屏）。

## 如何在线观看（推荐）

由于 **GitHub 仓库页面不会把 `.html` 渲染成网页**（点开只能看到源代码），要在线观看完整网页请使用 **GitHub Pages**：

1. 把本文件夹里的全部文件上传到你的 GitHub 仓库根目录（注意是仓库根目录，不是子文件夹）：
   ```
   index.html
   film.mp4
   music.m4a
   作品长图预览.jpg
   封面预览.jpg
   README.md
   ```
2. 进入仓库 **Settings → Pages**。
3. Build and deployment 里 Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`，保存。
4. 等待约 1 分钟，打开你的网站地址即可看到完整网页，视频可直接播放。

> 站点地址就是你的用户名域名，例如 `https://<用户名>.github.io/`。**不要**打开 github.com 上仓库里的 `index.html` 文件——那是代码页，不是网站。

## 只想快速看画面？

直接点开仓库里的 **`作品长图预览.jpg`**——这是整页展示页的长截图（1000×8580），GitHub 会直接渲染图片，无需配置 Pages。

## 文件说明

| 文件 | 用途 |
|---|---|
| `index.html` | 完整网页（1.9 MB，图片内嵌），用于 GitHub Pages |
| `film.mp4` | 成片视频（2.5 MB），页面播放器加载它 |
| `music.m4a` | 古风配乐（0.37 MB），页面播放器加载它 |
| `作品长图预览.jpg` | 整页长截图，GitHub 仓库内点开即可看画面 |
| `封面预览.jpg` | 首屏封面，本页顶部展示 |

## 技术说明

- 视频/音乐采用独立文件而非 data URI：浏览器对 `<video src="data:...">` 的长度有限制，3 MB 以上的内嵌视频会解码失败导致黑屏，拆成相对路径文件后正常。
- 所有路径均为相对路径，兼容 GitHub Pages 项目站点与用户站点。
